\section{Cluster Architecture}

The lab uses cluster-wide automation via ansible-playbook targeting inventory groups defined in \texttt{ansible/hosts}. Cluster management is handled through role-based provisioning rather than a dedicated orchestration layer.

\subsection{k3s Clustershell (Historical)}

Previous cluster shell groupings remain documented for reference:
\begin{verbatim}
all     -- all managed nodes
head    -- control plane nodes
compute -- worker nodes
gpu     -- GPU-enabled Jetson nodes
    \end{verbatim}

These groupings are now managed through Ansible inventory patterns rather than clustershell.

\subsection{Centralized Ansible Workflow}

\begin{enumerate}
    \item Role changes committed to stargate workspace
    \item Native ansible-test runs on stargate (zero external cost)
    \item Playbook execution targets remote hosts via SSH batch probes
    \item Changes verified via dynamic reachability: \texttt{ssh -o BatchMode=yes -o ConnectTimeout=3 franklin@\textless host\textgreater}
\end{enumerate}
