Minecraft Server

Minecraft section from the Bitsmasher Lab Operations Manual

Host and Location

The Minecraft server (Dreamland) runs on chonk.lab.bitsmasher.net (10.10.8.60), a primary compute host with RX 9070 / Navi 48 GPU. Server files are at /home/minecraft.

Previous host was skynet.lab.bitsmasher.net (10.10.16.10) during the CraftBukkit/early Paper era.

Core Plugins

Interactive Map

BlueMap provides an interactive 3D web map: chonk.lab.bitsmasher.net:8100

Storage

World data is approximately 13 GB. BlueMap assets are ~6.5 GB. All files on local disk (no NFS dependency for world data).

NO GIT-LFS: Chunk files and world data must not use git-lfs. Use bare git repos for any versioned world metadata.

Administrative Access

Operations automation via start.sh with a custom rcon-based controller. Management infrastructure ports: server 25565, BlueMap 8100, Plan analytics 8804.
