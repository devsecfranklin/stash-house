How to Join

  1. Launch any Minecraft Java Edition client (1.21.x compatible)
  2. Add server: minecraft.bitsmasher.net (port 25565)
  3. Authenticate via Mojang / Microsoft account (online-mode enabled)
  4. If whitelisted, you can join. Whitelist requests go through the Discord admin team.

The server has evolved across multiple eras: CraftBukkit (2012-2014), Forge modded (1.15.2–1.20.1), and current Paper stack. Read the full history.
