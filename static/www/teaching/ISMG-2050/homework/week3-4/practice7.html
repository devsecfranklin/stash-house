Part 1: Orientation and Print Area (30 pts)

  1. Open [your initials]Practice04.xlsx. Save as [your initials]Practice07.xlsx.
  2. You will now configure each sheet for professional printing:
  3. Sheet1 (Flash Fill Data):
  4. Page Layout > Orientation > Portrait
  5. Print Area > Set Print Area for the range A1:D15 (your Flash Fill output)
  6. Scale to Fit: Width = 1 page, Height = Automatic
  7. Insert in the Center Header: [Your Full Name] - ISMG 2050 Practice 4 Results
  8. In the Footer (right-aligned): Last modified: then use the Date & Time field to insert the current date automatically.
  9. "Conversion" sheet:
  10. Page Layout > Orientation > Landscape
  11. Print Area > Set Print Area for A1:D9
  12. Scale to Fit: Width = 1 page, Height = 1 page (ensure everything fits on a single printed page)
  13. Insert in the Center Header: Currency Conversion Report - Module 2
  14. In the Footer (left-aligned): Page then insert Page Number field.

Part 2: Page Breaks and Margins (30 pts)

  1. "TaxTable" sheet:
  2. View > Page Break Preview to see where Excel will split pages.
  3. If the table spans multiple pages, manually adjust page breaks: drag the blue dashed line to ensure all data fits on one page.
  4. If needed, insert a manual page break between rows 5 and 6: Select row 6, Page Layout > Breaks > Insert Page Break.
  5. Page Layout > Margins > Narrow (0.5" top/bottom, 0.7" left/right) to maximize data visibility.
  6. Set the Top Repeating Rows: $1:$1 so the header row prints at the top of every printed page.

Part 3: Headers, Footers, and Page Break Preview (25 pts)

  1. Return to Sheet1.
  2. In the header Left section, type: ISMG 2050 — Module 2 Practice
  3. In the header Center section, use the Page Number field (&P) to insert current page.
  4. In the header Right section, type: of &P pages.
  5. Insert a custom text watermark if available (Page Layout > Watermark): type "DRAFT" in gray.
  6. Switch to Print Preview (Ctrl+P). Verify each sheet renders cleanly with no data clipped off the right edge.
