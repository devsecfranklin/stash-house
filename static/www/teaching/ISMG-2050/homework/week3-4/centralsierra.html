Project Overview

You will complete an insurance commission workbook for Central Sierra Insurance. This assignment covers defined names from selection, XLOOKUP with approximate match, order-of-operations formulas, SUMIF branch aggregation, statistical distribution functions, logical IF classification, and CONCAT label assembly.

Step-by-Step Instructions

Step 1: Open and Save

  1. Open CentralSierra-02.xlsx in Excel Desktop (Microsoft 365).
  2. Save As to [your initials] CentralSierraIns.xlsx. Keep the original file open as your reference.

Step 2: Define Names from Selection

  1. Navigate to the Tables sheet. You will see two tables:
  2. Commission Level table in range A2:B6 (Level ranges in column A, Commission Rate in column B)
  3. Bonus Rate table nearby (Sales threshold and corresponding bonus percentage)
  4. Select the full commission level table range (A2:B6) including headers.
  5. Go to Formulas > Create from Selection.
  6. In the dialog, check only Top row (headers provide the name keys). Click OK.
  7. The names Commission_Level and Bonus_Rate are now defined names referencing these ranges. Verify in Formulas > Name Manager.

Step 3: Build Approximate-Match Lookup (XLOOKUP)

  1. Navigate to the Commissions sheet.
  2. In cell F5, build an approximate-match lookup for the commission rate:
  3. Formula: =XLOOKUP(E5, Commission_Level, Bonus_Rate, , -1)
  4. This uses XLOOKUP with match_mode = -1 for an approximate match (finds the largest value that is less than or equal to the lookup value). It returns the corresponding commission rate from the Bonus_Rate named range.
  5. Copy cell F5 down through F14. Verify each sales figure gets the correct tier rate applied.

Step 4: Enforce Order of Operations in Commission Calculation

  1. In cell G5, compute total commission with proper order of operations:
  2. Formula: =E5*(1+F5)
  3. This computes the gross sales amount multiplied by (1 + commission rate), giving total payout after commission is added to base. Note: parentheses ensure addition occurs before multiplication.
  4. Alternative formula: =E5+(E5*F5) -- equivalent result using explicit steps.
  5. Copy G5 down through G14. All 10 agents should now have their commission-adjusted total.

Step 5: Branch Earnings via SUMIF and Column Totals

  1. Scroll to the summary section starting at row 17. Column C lists branch names (North, South, East, West).
  2. In cell E18, compute each branch's total earnings using SUMIF:
  3. Formula: =SUMIF($D$5:$D$14, C18, $G$5:$G$14)
  4. This sums all values in G5:G14 where the corresponding D column matches the branch name in C18. The dollar signs create absolute references so the range stays fixed when copied.
  5. Copy E18 down to E19, E20, and E21 without applying any formatting (use Fill > Fill Only). You will format after all formulas are in place.
  6. In row 21, compute column totals: in cell E21, enter =SUM(E18:E20). Verify it matches the grand total from Commissions sheet (G5:G14).

Step 6: Statistical Distribution Analysis

  1. In the same summary area, compute statistical distribution on the commission-adjusted totals:
  2. Average: =AVERAGE(G5:G14) -- mean commission-adjusted total
  3. Mode (most frequent value): =MODE(G5:G14)
  4. Median: =MEDIAN(G5:G14)
  5. Format all three results as Currency with 2 decimal places.
  6. Note the relationship between Mean vs. Median -- this reveals whether the commission structure skews the distribution higher or lower.

Step 7: Logical Policy Classification on By Policy Sheet

  1. Navigate to the By Policy sheet.
  2. In cell F7, create an IF logical test to classify business policies:
  3. Formula: =IF(E7="business policy", "No", "Yes")
  4. This tests if the text in E7 equals "business policy" -- if true, returns "No"; otherwise returns "Yes". This flag identifies non-business policy entries for filtering.
  5. Copy F7 down through all agent rows to classify each entry.

Step 8: Assemble Labels on Tables Sheet via CONCAT

  1. On the Tables sheet, in cell D2, assemble an agent label using CONCAT:
  2. Formula: =CONCAT(Commissions!C5, " ", Commissions!B5, ", ")
  3. This concatenates the last name from column C and first name from column B of the Commissions sheet with a space separator and trailing comma.
  4. Test the result to confirm proper label formatting. Copy D2 down to create labels for all agents in your lookup table.

Step 9: Format and Finalize

  1. Select the branch summary range (E18:E20). Apply Currency ($#,##0.00) format.
  2. Apply Total Cell Style (double bottom border) to row 21 totals.
  3. Set print orientation to Landscape.
  4. Set print area to cover all relevant data on each sheet.
  5. Save your file and verify all formulas produce expected outputs.
