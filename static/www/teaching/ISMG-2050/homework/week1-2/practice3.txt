In this project, you open the workbook you created in Practice 2. You use navigation commands to
locate and edit data, add document properties, and set page options for printing.
---------------------------------------------------------------------------------------------------------------------------
File needed: [your initials]Practice02.xlsx (You created this file in practice 2)
Completed Project File Name: [your initials]Practice03.xlsx
1. Open a workbook and save it with a different name.
a. Open [your initials]Practice02. (Click Enable Editing if the workbook has opened
in Protected View.)
b. Re-save the file to [your initials]Practice03
c. Click Save
2. Select the Rental Days worksheet
3. Use the Name Box and the Go To command to locate data.
a. Click the Name Box, type d5, and press Enter.
b. Type 6 in cell D5 and press Enter.
c. Press F5 to open the Go To dialog box.
d. Type a8:c8 and press Enter. Three cells are selected
4. Use the Find command.
a. Select cell A5.
b. Click the Find & Select button [Home tab, Editing group] and choose Find.
c. Type 33 in the Find what entry box.
d. Click the Options >> button to expand the dialog box.
e. Verify that the options are Sheet, By Rows, and Formulas.
f. Click Find All. An alert box notes that Excel could not find “33” as a value. Excel
distinguishes between a value that you typed and a formula result (Figure 1-82).
g. Click OK to close the message box.
h. Change the Look in option in the Find and Replace dialog box to Values.
i. Click Find All. Cells H5 and H7 are found (Figure 1-83).
Figure 1-83 Look in option is set to Values
j. Select cell G5, type 10, and press Enter.
k. Select cell G7, type 8, and press Enter.
l. Click Find All again. No cells are found with the value of 33.
m. Close the message box and the Find and Replace dialog box.
5. Enter document properties.
a. Click the File tab and choose Info.
b. Click the Show All Properties link at the bottom of the properties list to expand the
list.
c. Click the Title text box and type [your initials]Practice03.
d. Click the Status text box and type Draft.
e. Click the Subject text box and type Rental days by property (Figure 1-84).
Figure 1-84 Properties in Backstage view
f. Click the Show Fewer Properties link at the bottom of the properties list.
g. Return to the worksheet.
6. Add a header and footer to grouped sheets.
a. Press Ctrl and click the Next Period tab.
b. Click the Header & Footer button [Insert tab, Text group].
c. Click the right section of the header area in Page Layout view.
d. Click the Sheet Name button [Header & Footer tab, Header & Footer
Elements group]. The code is &[Tab].
e. Click the Go to Footer button [Header & Footer tab, Navigation group] and click the
right section.
f. Click the File Name button [Header & Footer tab, Header & Footer Elements group].
The code is &[File].
g. Select cell A1 and click the Normal view button in the Status bar. The worksheets
are still grouped.
7. Change page setup options for grouped sheets.
a. Click the Page Layout tab.
b. Click the Orientation button [Page Setup group] and select Landscape.
c. Click the File tab and select Print to preview the printed sheets.
d. Click the Next Page arrow at the bottom of the screen to see the Next Period sheet.
e. Click the Prev Page arrow to return to the Rental Days sheet.
f. Click Normal Margins in the Settings area and select Custom Margins.
g. Select the Horizontally box in the Center on page area [Margins tab] (Figure 1-85).
h. Click OK to return to the preview.
i. Click the Next Page arrow to view the Next Period sheet.
j. Return to the worksheet.
k. Right-click the Next Period sheet tab and choose Ungroup Sheets
8. Save and upload your completed workbook (Figure 1-86).
