# Data Directory (/data/)

The data folder should serve as the central repository for all raw, unformatted files required for the Shelly Cashman textbook projects and lab assignments.

For Week 1, this must include:

- Frangold_Real_Estate_Raw.xlsx: The unformatted starting file for the primary Module 1 project
- Apply_1-1_Bicycle_Shop_3rd_Quarter_Sales.xlsx: The necessary file for the "Apply Your Knowledge" assignment.
- Extend_1-1_Kaseey_Vehicles.xlsx: The required workbook for the "Extend Your Knowledge" styling assignment.

By maintaining these files in a centralized data directory, the AI assistant can confidently direct students where to download their starting materials if they encounter issues with the Canvas interface.
