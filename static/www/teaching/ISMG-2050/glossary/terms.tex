\section*{ISMG-2050 Terms at CU Denver Business School}

\subsection*{Prompting}
In the context of ISMG-2050, prompting refers to the process of providing initial guidance or suggestions to help users generate a 
response.

\subsection*{Metadata}
Metadata in the context of ISMG-2050 refers to the data that describes and provides information about other data. This can include 
attributes such as authorship, timestamps, and file types.

\subsection*{Conditional Statement}
A conditional statement in the context of ISMG-2050 is a type of programming construct that tests whether a condition is true or 
false and executes different blocks of code based on the outcome. This allows for decision-making and branching logic within a 
program.
