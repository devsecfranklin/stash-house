SSH Configuration

Start the kadmin tool

kadmin.local -p admin/admin

Create the LDAP principal & keytab

addpol -minlength 8 -maxlife 7776000 -history 5 users getpol users ank -policy users franklin listprincs

Preauth: Put the pem files in /var/lib/krb5kdc since this is read/writeable by the KDC.

kinit root/admin kadmin -q 'addprinc -randkey WELLKNOWN/ANONYMOUS'

Realm is LAB.BITSMASHER.NET
Ansible does this part:

sudo apt install krb5-user krb5-config libpam-krb5 libpam-ccreds sudo apt install ldap-utils

Now set up the keytab for the host. Log in to the host to Create /etc/krb5.keytab file in place. Must be done as root user (not sudo)

sudo -i kinit root/admin kadmin # add host and ldap principals addprinc -randkey host/head1.lab.bitsmasher.net addprinc -randkey ldap/head1.lab.bitsmasher.net ktadd host/grimoire.lab.bitsmasher.net ldap/grimoire.lab.bitsmasher.net (quit) klist -ke /etc/krb5.keytab kinit franklin -X X509_user_identity=FILE:~/.ssh/franklin-cert.pem,~/.ssh/franklin-key.pem KRB5_TRACE=/dev/stdout ssh

Troubleshoot:

  • Check sudo hostnamectl
  • Check keytab "sudo klist -ke /etc/krb5.keytab"
  • Start sshd in console/debug-mode: mkdir /run/sshd && $(which sshd) -ddd
