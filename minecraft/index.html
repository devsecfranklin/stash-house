Forge Mods

We are running Forge 1.15.2 to make the server more fun.

Installing Forge

  • Download Forge 1.15.2
  • Once the download is finished, you should have a new file on your computer.
  • Click on the file and run the installer.

Installing Forge ModPack on Windows 10

Download mods to your computer using the steps below. Move the mods into your mods folder as directed and restart your Minecraft game.
  • Go to %appdata% and then press roaming.
  • There you should find a folder called .minecraft
  • Open the .minecraft folder.
  • Open the folder called "mods". If you don't see a folder called mods, create it.
  • Save the files from the list below into this "mods" folder.
  • Extract the file using a Zip utility.
