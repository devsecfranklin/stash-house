Forge Mods

We are using several Forge mods to make the server more fun. Download these to your computer. Move them into your mods folder.
  • Go to %appdata% and then press roaming.
  • There you should find a folder called .minecraft
  • Open the .minecraft folder.
  • Open the folder called "mods". If you don't see a folder called mods, create it.
  • Save the files from the list below into this "mods" folder.
