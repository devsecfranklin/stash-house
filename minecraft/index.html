Installing Latest Forge to Server

  • Download minecraft forge JAR to server.
  • mv forge-1.15.2-31.2.0-installer.jar forge/
    • >
  • java -jar forge-1.15.2-31.2.0-installer.jar --installServer
  • Move the new forge jar into the /home/minecraft/forge directory.
  • Start the server with the script forge/minecraft.sh in a screen session.
