Download minecraft forge JAR to server. Install it like so: mv forge-1.15.2-31.2.0-installer.jar forge/ java -jar forge-1.15.2-31.2.0-installer.jar --installServer move the new forge jar into the forge directory. Start the server with the script forge/minecraft.sh in a screen session.

Notes For Admins

When a player joins the server, they have almost no permissions. This is to prevent griefing and such. You will have to move them from "default" group to the "player" group once you are sure they are not insane, griefing, etc.

The command to change someone to player is:
/manuadd <playername> player
You can also demote a griefer like so:
/manuadd <playername> default

Custom Commands

You can point players to these custom commands:
/websiteWebsite with information about the server.
Command Description
/register Explain to the player that they need to contact an admin to get out of DEFAULT group.
/townhelp Help with towny
